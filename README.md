# Zuma Extreme

Welcome to Zuma Extreme! This project is built using the Godot Engine. 

## Requirements
- **Godot Engine 4.x** (This project uses Godot 4+)

## Installation & Setup

To run or edit this project, you will need to download and install the Godot Engine:

1. **Download Godot**:
   - Go to the official Godot website: [https://godotengine.org/download/](https://godotengine.org/download/)
   - Download the **Godot Engine 4.x** standard version for your operating system.

2. **Open the Project**:
   - Extract the downloaded Godot zip file and run the Godot executable.
   - When the Godot Project Manager opens, click the **Import** button on the right side.
   - Click **Browse** and navigate to the folder where you cloned or downloaded this repository.
   - Select the `project.godot` file in the project folder and click **Open**.
   - Finally, click **Import & Edit** to open the project in the editor.

3. **Run the Game**:
   - Once the project is open in the Godot Editor, you can press the **Play** button (or `F5` on your keyboard) in the top right corner of the window to run the game!
